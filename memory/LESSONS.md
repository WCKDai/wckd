# LESSONS.md

*Read at the start of every Canvass and every Bar-setting. Append under the nearest domain heading; each lesson cites the artifact that taught it. A lesson that would not change a future action is not a lesson.*

Format: **situation** → what we did → what happened → **do this next time** → *(source)*

## Protocol (applies to every want)

- **A want arrives with a solution attached** ("build me a React dashboard") → the Listener wrote the capability underneath and kept the solution as a stated preference → Canvass found a kept platform that met the Bar better → **always write the capability; let the Judge weigh the preference against the landscape** → *(examples/air-quality-monitor/brief.json)*
- **A capability looked like it needed a BUILD** → Scout tried the obvious open-source platform instead of reading about it → the platform already covered alerting and history → **"tried" beats "read about"; most BUILD verdicts die on contact with a trial** → *(examples/air-quality-monitor/landscape.json)*
- **The Graveyard was the real spec** → DIY sensor projects died of drift, not of code → the only BEND in the plan was calibration and a watchdog → **read the Graveyard before drawing anything** → *(examples/air-quality-monitor/landscape.json#graveyard)*
- **Run cost was "negligible"** → the Quartermaster itemized it anyway → cloud history storage was the largest line and drove a local-first decision → **run cost is never a word; it is a number with a class** → *(PROTOCOL.md §9)*

## Physical / hardware

- **BOM priced at quantity one** → unit cost at planned volume came in far lower, but MOQ and lead time came in far longer → **price at the planned volume and put long-lead items in their own work orders** → *(SKILLS.md unit-costing)*
- **One golden unit tested** → field drift appeared on units from a different batch → **physical stress campaigns use units from more than one batch** → *(agents/breaker.md)*

## Digital / software

- **Rollback existed as a document** → the drill found it needed a secret nobody had → **a rollback that was not rehearsed does not exist** → *(agents/shipper.md)*
- **Validator used the builder's environment** → "works on my machine" leaked into a proof → **clean reproduction is part of the proof, not a nicety** → *(agents/validator.md)*

## Cost and prospects

- **No kill criteria written** → the project could not fail on paper, so it failed in production → **a prospect with no "don't" condition is not a prospect** → *(agents/prospector.md)*
